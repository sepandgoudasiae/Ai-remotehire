# Editor Guide

## Homepage

Edit the page assigned under **Settings → Reading → Homepage**. All ordinary marketing content is stored as blocks. Use List View to navigate major groups: Hero, Intro, Solutions, Process, Objections, FAQ, and Final CTA.

## Patterns

Use **Add block → Patterns → AI-RemoteHire** to insert the approved hero or final CTA. Patterns copy editable blocks into the page; editing a page does not globally alter other copies.

## Contact details

Edit public contact details under **Appearance → Customize → Business details**.

## Request Talent form

Install and configure an approved form plugin, add its shortcode to the Customizer, and insert `[airh_contact]` on the Request Talent page. Do not add SMS consent until the final consent language, storage, routing, and suppression workflow are verified.

## Images

Use licensed/approved images only. Add descriptive alt text for meaningful images and blank alt text for decorative images. Preserve image dimensions and use WordPress-generated responsive sizes.
